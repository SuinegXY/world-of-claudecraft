版本公告

更新日志

发布日期: 2026年7月16日

第一部分

官方更新 (v0.26.0)

界面优化

  • 优化角色【查看 (Inspect)】界面的角色展示, 角色现在会以 3/4 身全身像显示, 不再是放大的头像特写。
  • 修复【天赋】界面「创建 Build」面板被裁切的问题, 窗口缩放时也能正确自适应。
  • 合并游戏内重复的 Discord 入口, 只保留一个统一入口, 并新增「直接加入 Discord 服务器」按钮。
  • 修复背包物品右键操作:
    • 右键: 使用/装备物品
    • Shift + 右键: 销毁物品
  • 修复聊天输入框高度计算, 使占位文字和边框显示正常。
  • 修复聊天频道颜色显示及默认发送频道提示。
  • 修复目标框、聊天框在修改 UI 缩放后拖动位置错误的问题。
  • 新增首次进入游戏时的镜头模式选择 (经典模式 / 鼠标镜头模式)。
  • 修复网络断开时登录界面显示英文 "Failed to fetch" 的问题, 现在会显示本地化提示。

游戏玩法

稀有怪物

  • 调整稀有怪物任务掉落判定。
  • 稀有怪任务物品现在按照实际伤害贡献发放, 而不是按照最后 Tap 玩家发放。
  • 修复宠物单独击杀稀有怪导致任务奖励归属异常的问题。
  • 防止玩家利用宠物长期垄断稀有怪刷新。

战斗

  • 修复高速转动镜头时角色朝向不同步的问题。
  • 修复矮栅栏错误阻挡法术视线的问题。
  • 修复码头平台没有碰撞, 可直接穿过去的问题。

输入

针对 Firefox:

  • 修复 Pointer Lock 获取失败导致无法正常鼠标视角的问题。
  • 修复高 DPI 显示器鼠标视角速度异常的问题。
  • 修复不同鼠标按键切换镜头时的多个边缘情况。

音效

  • 增强 Mob 音效资源检查, 错误命名的音频现在会直接报错, 而不是静默忽略。
  • 多个相似怪物现在可以共享同一套语音资源。
  • 修复 SFX Studio 发布时错误扫描整个音效目录的问题。
  • 新增音效资源规范:
    • 单声道 / 双声道检查
    • 文件命名检查
    • 统一音效资源标准

世界

  • 新增采集成功事件, 为后续采集音效系统提供支持。
  • 修复 Gravewyrm Sanctum 可无限刷收益的漏洞。
  • 修复 Vale Cup 每日任务奖励在服务器重启后无法正确发放的问题。

本地化

  • 更新多个语言翻译。
  • 修复背包右键提示文字: 从「右键销毁」改为「Shift + 右键销毁」。
  • 更新相关非拉丁语言翻译。

性能优化

  • 优化地形生成, 大幅减少无效噪声计算。
  • 新增服务器按区域统计 Mob 更新性能, 便于定位性能瓶颈。
  • 增加压力测试覆盖。

测试

新增大量自动化测试, 包括:

  • 稀有怪掉落
  • 战利品保留
  • Pointer Lock
  • UI 布局
  • 背包右键逻辑
  • 服务器连接
  • 天赋窗口
  • 音效规范
  • 采集事件
  • 等多个模块

其它

  • 忽略本地 .worktrees/ 目录。
  • 更新 i18n 校验文件。
  • 修复若干 UI、注释和代码风格问题。

第二部分

独家更新

以下为本服务器的独家玩法调整, 仅在本服生效:

  • 职业属性全部翻倍
  • 武器伤害翻倍
  • 装备额外属性为 5 倍
