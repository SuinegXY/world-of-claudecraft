# World of ClaudeCraft v0.40 中文摘要

发布日期: 2026年8月25日

v0.40 以经济、社区与输入为主: $WOC Exchange 玩家市场落地 (默认关闭, 待上线清单完成), 每个城镇告示牌变为公会招募板并支持请愿, 手柄改为 FFXIV 风格十字热键条, 触屏 HUD 按拇指可达重做, GPU 调度把最严重卡顿从 5.6 秒压到半秒以内。术士达到团本可用水准, 练级区掉落回到经典概率, 潜行贼补完长期欠账, 教程岛开始教手柄玩家。独家服在本版本之上继续保留数值倍率、施法不受伤打断、掉落副属性、团队副本可单人进入等本服规则。

## 亮点

- $WOC Exchange: 拍卖、一口价、定向报价、保证金与坐骑/机甲涂装交易; 本构建默认关闭。
- 城镇告示牌变为全服公会板: 招募状态、公开名册、未入会玩家可向招募公会请愿。
- 手柄十字热键条: 扳机展开 8 格, 右肩键切换两套, 共 16 个动作; 含自动选目标与十字键窗口导航。
- 触屏 HUD: 径向环 4x5 两页、消耗品进可达区、十格快捷条与独立编辑, 避免战斗中误改键位。
- 性能: 统一 GPU 调度, 最差单次卡顿 5.6 秒降至 0.47 秒; 进世界加载约 23.7 秒降至 16.0 秒。
- 职业: 术士三系贴近 200 DPS 英雄合同; 增强萨满与火焰法师从上方收回同一合同; 潜行贼隐身套件补完。
- 练级掉落: 14 只普通怪的绿/蓝掉落从 10-30% / 4-8% 回到 2% / 0.2%; 稀有、精英、首领与任务掉落不变。
- 裂隙: 忙碌裂隙服 tick 变快; 打赢后的传送门保留 15 分钟, 团灭不再立刻丢掉战利品。
- 新手岛: 手柄提示按实际重映射绘制; 毕业渡船落到海港镇并保持过场。
- 本地化: 21 个语言全部填满, 含市场、公会板、教程与任务文本。

完整官方条目以 GitHub Releases `v0.40.0` 为准。本摘要只保留玩家向要点, 工具链与 CI 细节从略。
