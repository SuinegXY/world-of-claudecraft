v0.29.0 更新日志

概要
v0.29.0 收官专业 2.0, 将其打造成完整、平衡的制造成长与经济体系。
本版本会一次性重置每位角色的专业技能等级至 0, 使所有人从最终精通曲线重新起步。
同时重调地下城与团队副本难度、补齐职业掉落缺口、大改多块界面、上线重制原声、
强化追逐镜头手感, 并落地一批服务端稳定性与安全加固。

亮点
专业 2.0 收官: 精通曲线与技能上限、采集施法、钓鱼小游戏、委托制造与工匠契约、
附魔、接纳任务、专业事迹与定制美术全部齐备。
专业技能一次性清零: 请查收游戏内邮件 (公会大厅来信说明重置范围)。物品、配方、
工具、材料、银行、金币、接纳进度、头衔、事迹、名望与任务全部保留。
正式说明见 wiki: https://worldofclaudecraft.com/wiki/professions
副本与 Nythraxis 难度/经济重调, 含英雄难度专属 Onrush 冲锋与首领控制免疫。
制造窗改为分页展示书, 角色面板、世界市场、任务日志与商人窗一并重设计。
区域与战斗音乐改为流式重制原声; 追逐镜头为跳跃、落地与进区增加重量感。
鉴权令牌作用域在 WebSocket 与管理边界严格校验; 夜间留存清扫控制数据库体积。

专业 2.0
首次登录 v0.29.0 时, 每名角色的制造与采集熟练度清零一次, 其余进度不动;
受影响角色会收到公会大厅说明信。重置只执行一次, 不会反复触发。
专业 wiki 按技能拆页重写 (八制造、四采集、经济页与 FAQ), 训练费、配方获取、
节点档位、施法时间、钓获概率与附魔数值均来自实机常量。
制造熟练度改为四态精通曲线 (满/半/四分之一/零), 并按专业封顶:
采矿/伐木/草药 100, 制造与附魔 125, 钓鱼 200。
采集节点改为计时施法, 工具档与熟练度缩短时间; 工具档门槛显示在提示与小地图。
钓鱼新增咬钩小游戏: 见浮标提示后在窗口内收竿 (鱼竿档位加宽窗口), 否则跑鱼;
熟练度越高, 渔获从垃圾偏向食用鱼。
委托制造使成品为交易绑定 (首次接受者绑定); 工作台大师提供按档收费的工匠契约解绑。
附魔幅度收为完工加成; 附魔熟练度按分解输入品质分档。
原型接纳改为大师 NPC 的按原型任务链, 含庆祝、里程碑邮件与工单节奏。
新增 26 项专业事迹 (含 Guildsworn / Masterwright / Master Angler 等头衔与 Steam 成就,
以及各制造满级宗师头衔)。
专业图标、采集图标、原型纹章、材料与事迹改用定制美术。
材料、附魔、头衔、事迹与工具启用原创名称 (Sheenleaf、Glyphsteel、Skysilver、
Chime Essence 等); 物品 id 不变, 已有库存仅显示新名。
绑定物受 Sell All Junk / 部分堆叠出售保护; 暴利奖励合并为单条堆叠掉落;
修正正收益配方; 制造/采集物提示显示工匠与采集者出处。
制造窗改为分页展示书 (配方卡、品质槽、材料短缺着色); 原型环窗配身份卡与环轮。

职业、战斗与遭遇
地下城与团队副本难度重调: 普通 Gravewyrm Sanctum 怪物生命翻倍, 垃圾伤害下限 300 /
首领 600; 四座英雄五人本怪物生命翻倍, 伤害下限 500; Nythraxis 生命 120,000,
普通下限 600 / 英雄 1200。
九种近战战士/守卫型英雄五人本怪物获得 Onrush (开怪冲锋短晕); 普通难度不会冲锋。
最终首领与具名中段首领在两种难度均免疫控制与减速 (不仅英雄)。
战士化身可在恐惧/昏迷中真正破控 (破玩家与小怪控制, 不破首领控制)。
Hellglass Ward 护盾改挂在术士自身, 不再挂到敌方目标。
Mistcaller's Fang 可正确配合背刺与伏击使用。
掉落补齐约 41 件开放世界 / 地下城 / 团队装, 填补职业与专精缺口
(含野性德鲁伊武器、萨满/圣骑士施法锁甲、首件智力盾, 以及 Korzul / Nythraxis 新掉落)。
对尸体一次交互可同时采集与拾取, 两段不再互相卡住。
带充能技能显示金色充能角标与回充扫光。
竞技场掩体可视范围与碰撞对齐, 无法再穿出坑外。
绑定物品无法再经商人买回洗成非绑定。

界面与社交
角色面板与检视改为展示式布局: 品质光效装备槽环绕实时 3D 模型, 属性与攻防面板更清晰。
世界市场改为横屏多列网格; 护甲筛选覆盖颈/戒/副手; 建议要价上限为商人价 10 倍。
任务日志与商人窗改横屏; 界面选项拆为综合 / 框架 / 聊天 / 战斗页签。
地下城查找目录选中时保持滚动位置。
桌面侧栏拆为两列以适配矮视口; 悬停飞出层正确盖住内列。
经验条移到动作条下方、贴底显示。
登录后进入角色选择; 「新闻与更新」栏取代旧欢迎屏。
新增选项可隐藏其他玩家姓名板 (当前目标仍显示)。
动作条布局按角色存服务器, 跨设备 / 浏览器跟随。
邮件包裹 30 天后过期并退回发件人一次; 撰写窗可输入包裹数量, 暂存物品不再清空表单。
武器提示显示武器类型; 背包物品提供分解 / 回收 / 应用附魔右键 (带确认);
相同物品可跨背包、银行与交易堆叠。
职业色在聊天、框架、小地图点与模型染色上刷新, 战士与圣骑士再提亮。
/afk 在姓名板与社交窗显示 AFK 标记; 公会名册按在线分组并支持隐藏离线;
职员聊天行带服务器盖章的彩色角色标签 (客户端无法伪造)。
持有者 / 贡献者徽章升级为 Ascendant Sigils, 含分档纹章与淡姓名板光晕。
确认框可用 Enter / Space 确认; 尸体拾取窗标签、提示与快捷键更清晰。
移动端: 全屏面板隐藏底栏以拉高窗口; 背包右键菜单弹在面板上方而非背后。

镜头、渲染与音效
追逐镜头手感栈: 跳跃/落地阻尼弹簧臂、速度前瞻、加速与升级 FOV 踢、落地顿挫、
进区远景扫视、死亡漂移一次; 全部尊重减少动态, 手动输入取消扫视。
与主手同类型的副手会镜像军械库武器外观; 角色面板、检视转盘与登录名册渲染已购皮肤。
角色预览冷启动缓存失败可独立重试, 不再永久坏掉。
区域与战斗音乐流式重制音源, 交叉淡入淡出与闪避逻辑不变; 听不见的提示会暂停流以省带宽。
锻造环境音改为真实录音无缝循环; Thornpeak Heights 风声下调至与同级区域一致。
小地图饰以手工描金斑点边框; 低画质预设改为纯色边框, 不涉及可操作信息。

稳定性与性能
事件批次与地下城查找板改为每 tick 序列化一次; 快照兴趣查询按格子共享。
排行榜、事迹稀有度与项目统计加缓存与单飞读取; 竞技场天梯与项目统计加每 IP 限流。
修复三处数据库热点: 终身 XP 排行避免顺序扫描、每日奖励封禁检查拆成索引路径、
活动修剪批次不再整表排序过期集。
夜间留存清扫按可配置窗口修剪性能报告、奖励事件、在线采样与在场行;
旧游玩会话先折入终身汇总表再删除。
Vale Cup 读出在服务器负载下不再因 tick 步长门控遗漏而卡住。
动作条布局编辑在登出与标签隐藏时刷盘, 关窗前几秒的改动也能同步到其他设备。
强制改名会同步清扫该角色背包、银行与装备上的制造署名, 保持自制折扣。
iOS 使用受限渲染配置, 限制临时资源, 避免中画质下 WebKit 进程被杀。

服务端、安全与平台
WebSocket 进世界与两条管理 API 路径要求完整作用域令牌; 只读令牌无法提权进世界或管理。
桌面 Discord 登录可可靠回到应用 (含已有账号、首次建号与 2FA 关联路径)。
Docker 镜像改用 node:26-slim; CI 同步 Node 26。
离线游玩仅开发构建可见, 生产构建不再暴露; 世界状态芯片改为显示「已创建角色数」。

兼容与升级
专业技能一次性清零: 首次登录后清零制造与采集熟练度并投递说明信;
配方、工具、材料、银行、金币、接纳、头衔、事迹、名望、任务与邮件不动。
专业物品仅改显示名, 物品 id 不变, 玩家与运维无需额外操作。
专业线面移除过时成员 (activeArchetype 等); 自定义 IWorld 需迁到 craftingIdentity 镜像。
自建服需 Node 26 (Dockerfile 基于 node:26-slim)。

新库表/视图/列 (play_session_totals、account_ip_associations、
daily_reward_excluded_accounts、characters.hotbar_layout) 启动时加法迁移, 无需手工。
