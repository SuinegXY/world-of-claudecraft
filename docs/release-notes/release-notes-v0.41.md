# World of ClaudeCraft v0.41 中文摘要

发布日期: 2026年9月1日

v0.41.0 打开 Ignivar 团本与熔炉战利品档, 补完银行与材料仓库, 让 HUD 可自由解锁与排布, 并把大量战斗、移动、手柄、桌面与性能修复打进同一版本。独家服在本版本之上继续保留数值倍率、施法不受伤打断、掉落副属性、团队副本可单人进入等本服规则。

## 亮点

- Ignivar 团本: 从龙地入口进入锻炉升降、初淬大厅、Ignivar 竞技场、熔火装配与内熔炉; Ignivar 与 Varkhul 有独立机制、攻略、语音与普通/英雄调校。
- 熔炉装备档: 201 件职业套装、徽记兑换、首领表、散件、武器、盾与传说掉落; 英雄与普通分表。
- 材料仓库: 银行第三页按材料分别存材料, 初始每种 40, 四档升到 200; 野外制作先花背包再从仓库扣, 副本内只用随身材料。
- 银行背包插槽: 四个顺序解锁的插槽, 普通包扩通用格, 材料包只扩材料格; 七个新包, 含最大的织缚材料包 (24 格)。
- HUD: 「解锁界面」一次放开所有可动框; 可拖动、键盘微调、缩放、单独重置, 并记住布局。
- 手柄与触屏: 地面指向与蓄力技能可从手柄/触屏施放; 十字热键条与触屏栏不再抢同一片空间。
- 战斗与移动: 练级技能曲线更平滑; 自由拾取落到真正点尸体的人; 在线移动改精确对账预测; 裂隙内同样生效。
- 本地化: v0.41.0 全部 21 个语言填满。

完整官方条目以 GitHub Releases `v0.41.0` 为准。本摘要只保留玩家向要点, 工具链与 CI 细节从略。
