# World of ClaudeCraft v0.38 中文摘要

发布日期: 2026年8月17日

v0.38 以渲染栈升级与战斗公平性修复为主: Three.js 升到 r185 (冻结矩阵相机/世界矩阵新语义), 复活要求距离与视线, 英雄团本终局金币与 Sanctum 金农场收束, 以及桌面/原生壳与 OTA 相关加固。独家服在本版本之上继续保留数值倍率、施法不受伤打断、掉落副属性等本服规则。

## 亮点

- Three r185: 冻结节点世界矩阵刷新与瞄准走 `refreshFrozenWorldMatrix` / `lookAtFrozen`。
- 复活: 每次复活都要求距离与视线 (含范围保护)。
- 英雄团本终局金币基数上调; Sanctum / Zulgar 农场金掉落收束。
- 自运动预测在长渲染帧上保持平滑。
- 桌面壳与差分 OTA / Docker 构建上下文若干加固。

## 说明

完整官方条目以 GitHub Releases `v0.38.x` 为准。本摘要只保留玩家向要点, 工具链与 CI 细节从略。
