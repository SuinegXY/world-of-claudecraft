2026-7-18

v0.27.0 更新日志

概要
v0.27.0 是近期体量最大的版本之一, 覆盖职业、系统与内容约 440 次提交。
重点包括: 战士三专精重做与九职业天赋 2.0 抉择行、法师时空术治疗专精、
专业 2.0 前三阶段、游戏内 Solana 钱包与 Claudium 商店、卡牌对决小游戏、
桌面欢迎界面与启动器、全量自定义音效、附魔大改, 以及可拖动的小队/团队框。

亮点
战士天赋 2.0: 战士完整重做为战技(武器)/血涌(狂怒)/铁卫(防护)三专精,
各有专属技能、三种姿态与六层抉择行天赋树; 九职业均已切到抉择行体系。
法师时空术治疗专精: 奥术改为完整治疗专精「时空术」, 含时间回响、以太涌动、
回溯团队冷却、悬浮沙漏、战斗复活与时间加速(嗜血同类); 火焰与冰霜专精全面重做。
专业 2.0 一至三阶段: 原型接纳任务上线, 成对原型头衔取代单专业头衔,
产出质量改为确定性并保留杰作触发, 组合配方校验修复, 新增多件施法向制造装。
游戏内 Solana 钱包与 Claudium 商店: 浏览器扩展 / 手机深链 / Electron 交接三种连接,
并新增 USDC 支付通道, 购买非托管, 玩家自行签名。
卡牌对决: 开局区卡牌大师 NPC 主持权威 1v1 卡牌小游戏, 并有对应事迹。
AAA 欢迎界面与桌面启动器: 登录后欢迎屏展示更新、Discord 与角色展示;
Electron 在 Windows / Linux / Mac 混合显卡设备上强制独显。
自定义音效全量启用: 130 个手工音效键成为正式音频, 含闲置怪物叫声与事迹解锁音。
附魔大改: 新增 Greater 档, 奥术碎片成为 Greater 唯一材料; 基础档按构筑补齐可选。
可配置可拖动小队/团队框: 成为可锁定位置的 MovableFrame, 界面选项可调样式与缩放。

职业与天赋 2.0
战士: 三专精、姿态栏回归 HUD、共享冲锋/打断/斩杀等基础技, 以及完整抉择行。

法术暴击接入共享暴击加成、恐惧按伤害比例解除等。
法师三专精: 时空术治疗循环、冰霜/火焰触发引擎与技能更名, 以及自定义图标。
猎人/盗贼/术士/德鲁伊/圣骑士/萨满等抉择行与专精身份调整, 天赋界面与特效增强。
