# World of ClaudeCraft v0.37.0 中文摘要

发布日期: 2026年8月13日

v0.37.0 以客户端性能与平台交付为主: 收官登录预览卡顿治理, 原生壳落地差分 OTA 更新与可见更新门, Android 安装包压到 Play 商店上限内, 地形贴图改为独立 KTX2。玩法侧补上背包物品锁定、世界市场体验、Shift+Tab 反向选目标, 以及裂隙熔炉线令默认关闭的安全修复。全量 21 语言零 pending。

## 亮点

- 登录与军械库预览卡顿大幅收束 (最差预览停顿约 754ms 到 42ms)。
- 原生壳差分 OTA: 按文件哈希只下变更, 带进度门与失败回退整包。
- Android 基模块压到约 68 MB 压缩体积 (媒体进安装时资源包)。
- iOS 远距区块在内存压力下回收, 缓解长会话杀进程重载。
- 地形等贴图改为独立 KTX2, 常驻显存约 212 MB 降到约 41 MB。
- 裂隙熔炉三条线令默认关闭 (`RIFT_FORGE_ENABLED`), 防未上线 UI 被线端滥用。
- 背包 / 银行 / 公会银行物品可锁定, 禁止卖店、分解与当材料。
- 综合频道按账号限流, 管理端可查可配。
- Shift+Tab 反向选目标; 世界市场按价排序并显示护甲类型徽章。

## 战斗与内容

- 恢复比例恐惧递减 (修正重构后被压成固定时长的回归)。
- 裂隙首领死亡圈施法时间上调, 并加全表回归护栏。
- 训练假人不吃 Sentence 处刑统计; 宠物潜行察觉距离修正。
- 战斗记录新增生命 / 主资源与仇恨表采样。
- 一区狗头人改用原创模型; 战场 Unstuck 在对局内可用。

## 平台与安全

- 差分 OTA 清单校验失败即关; 裂隙熔炉线令默认拒绝。
